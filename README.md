# 无名剧场

SillyTavern 扩展，当前版本 **0.5.1**。在奶油色纸雕剧场里选择剧目，读取当前角色与聊天，生成独立 HTML 番外。每次一次写完有开端、发展和结局的完整故事，双方言行依据角色设定与 Persona。成品留在剧场，可反复查看或下载，**不会发送或新增聊天消息**。

## 安装与更新

需要 SillyTavern 1.14.0 或更新版本，并先配置可正常生成回复的模型连接。

推荐安装：在酒馆的「扩展 → 安装扩展」中粘贴 `https://github.com/jiuyi777/interlude-theatre`，安装完成后刷新页面。之后可通过扩展管理器更新。

手动安装：把本插件文件夹放到 `SillyTavern/public/scripts/extensions/third-party/interlude-theatre/`，确认 `manifest.json` 位于该文件夹第一层，然后刷新酒馆。打开输入框旁的扩展菜单，选择「无名剧场」。

手动更新：关闭剧场，用新版本文件替换插件文件夹内的同名文件后刷新酒馆。剧目、收藏与演出记录保存在酒馆扩展设置中，更新插件文件不会主动清空这些设置。若通过 Git 仓库安装，使用酒馆扩展管理器中的更新按钮。

## 使用

1. 打开任意角色聊天或群聊，从扩展菜单进入「无名剧场」。
2. 单击卡片选剧目；再次点击已选卡片，查看或修改描述。保存后的描述会参与下一次生成。
3. 点击「拉开帷幕」，选择是否承接当前聊天，以及简洁 HTML、静态或动态美化。
4. 确认后读取此刻的上下文，使用当前模型连接制作 HTML。结果展示在剧场纸页内，支持展开细节等 HTML 原生交互。
5. 点击「下载 HTML」保存离线成品；以后从「演出记录」再次查看。点击「读取最新上下文再制作」回到剧目，再确认开演时读取最新聊天。

每次生成都重新读取当前聊天。开启承接时读取预算内最近的主聊天，过滤带旧版剧场标记的消息；关闭时只使用角色卡与 Persona。“不发送”指不写入聊天消息；制作仍会把所选上下文作为生成请求交给你当前配置的模型服务，并消耗模型额度。插件不会在后台自动读取其他聊天，也不自动收集整个聊天库、世界书或其他扩展的私有数据。

所有页面和生成文档使用无下划线排版。动态档位使用 CSS 动画并尊重系统的减少动态设置。结果在隔离框架里预览，移除脚本、表单、跳转及外部资源；需要 JavaScript 或远程图片的模型输出会被简化。

## 剧目管理

剧目库可搜索、收藏、导入。导入支持单个 JSON、数组、`{"scripts": [...]}` 和带 `entries` 的世界书合集，先预览再确认收录。

最小剧目格式：

```json
{
  "title": "雨夜来信",
  "description": "一封没有署名的信，让两人重新谈起雨夜的约定。",
  "prompt": "让 {{char}} 与 {{user}} 在雨夜收到一封信，依据双方性格写出完整经过与结局。"
}
```

可选字段包括 `mode`、`acts`、`tags` 和 `cover`。导入预览可转换角色宏。导演室可设置主演、演出方式、备注与默认美化。

演出记录最多保留 100 条，HTML 总量限制约 200 万字符；达到限制后较老记录只保留标题等信息，需长期保留的成品请及时下载。生成内容随酒馆扩展设置保存，不随插件源码上传。

## 常见问题

- 找不到入口：确认没有多套一层文件夹，刷新酒馆，再打开扩展菜单。
- 提示先打开聊天：进入一个角色聊天或群聊后再开演。
- 生成失败或空白：确认酒馆模型连接能正常回复；缩短导演要求后重试。失败不会增加成功记录或写入聊天。
- 看不到全部历史聊天：按长度预算保留最近内容，过长的单条消息会截取尾部，不是无限上下文。
- 下载的动态效果较少：支持 HTML/CSS 与原生展开交互，不运行模型提供的脚本。

## 验证范围

使用宿主 `SillyTavern.getContext()`、`getCharacterCardFields()`、`substituteParams()` 与 `generateRaw()`；生成路径不调用 `saveReply()` 或 `saveChat()`。

本地模拟宿主检查覆盖切换上下文、编辑描述、零聊天写入、HTML 保存、空响应恢复和无下划线处理；本地浏览器示例验证预览页面。真实酒馆的模型连接与输出质量仍需在实际宿主中确认，本地固定示例不代表真实模型验收。

开发检查：安装测试依赖 `jsdom` 后，执行 `node tools/test-html-drafts.mjs <安装 jsdom 的目录>`。
