# 无名剧场

SillyTavern 扩展 · **0.6.0** · 作者 **Zeya**。
在奶油纸雕剧场的同一张纸页里填写要求、生成完整故事、编辑正文、保存收藏、追加后续篇章。生成与续写均不自动写入聊天。

## 安装与更新

需要 SillyTavern 1.14.0 或更新版本，以及已配置的模型连接。

**首次安装：**打开酒馆「扩展 → 安装扩展」，粘贴下面的仓库地址，安装完成后刷新酒馆：

```text
https://github.com/jiuyi777/interlude-theatre
```

**从仓库更新：**在扩展管理中找到「无名剧场」，检查并安装更新，然后刷新酒馆。本插件不会自动更新。刷新会中断正在生成的内容，请先完成当前创作。

**使用压缩包：**从 [0.6.0 下载页](https://github.com/jiuyi777/interlude-theatre/releases/tag/v0.6.0) 下载 `interlude-theatre-0.6.0.zip`，将其中的 `interlude-theatre` 文件夹放到 `SillyTavern/public/scripts/extensions/third-party/`。确认 `manifest.json` 位于插件第一层，然后刷新酒馆。通过压缩包安装的版本，再次下载新版覆盖更新；替换文件前保留原插件目录。

打开聊天输入框旁的「剧场」，或扩展菜单中的「无名剧场」。有些酒馆主题没有输入框快捷入口，可以使用扩展菜单。

## 0.6.0 更新

- 在同一张纸页完成填写要求、生成、阅读、编辑、保存、收藏和续写；续写追加新篇章，保留前文。
- 作品与编辑草稿保存在本机，支持重开恢复、导出备份和导入副本，取消旧版按条数或字符数裁剪正文的限制。
- 点击「写入聊天」才新增消息，核对目标聊天、核验保存结果，并阻止同一作品版本重复写入。
- 增加输入框旁的快捷入口；清除下划线、底部装饰线和滚动条外观，保留正常滚动及原有纸雕素材。

## 使用

1. 点「选剧目」选择插画卡片，或点「自己写」。填写标题与「这次想写什么」，高级备注在「更多写作设置」。
2. 点「生成完整故事」。参考当前聊天时，只提供预算内最近的主聊天和角色资料；关闭时使用角色卡、Persona 和本次要求。请求发送到酒馆已配置的模型，消耗该服务额度。
3. 结果出现在当前纸页。点「编辑正文」修改文字，点「保存作品」保存；编辑草稿也会自动保存到本机。编辑采用清晰段落排版。
4. 点「收藏作品」，以后从「我的作品」筛选查找。剧目库中的收藏仍代表剧目模板。
5. 点「继续创作」，填写后续要求。新内容作为新篇章追加，原故事保留；上方篇章选择可切换阅读、编辑。续写需要原角色聊天，前文超出模型预算会明确提示。调整写作要求后点「另写一版」会生成另一部作品，旧作品保留。
6. 如需进入主聊天，核对纸页显示的目标，再点「写入聊天」。以正文文字新增一条角色消息，不自动触发模型。相同作品版本在同一聊天只写一次，成功后显示「已写入此聊天」。修改正文并保存后可以手动写入新版本。
7. 「下载作品」导出全部篇章的离线 HTML；「我的作品 → 导出作品备份」导出可恢复的 JSON。换浏览器或设备后，用「导入备份」恢复为副本，原作品保留。

## 保存在哪里

作品全文、收藏和编辑草稿保存在**当前浏览器、当前酒馆站点的 IndexedDB**；不是云端同步。作品按酒馆扩展设置中的库标识隔离。浏览器清理站点数据、无痕窗口关闭或浏览器自动回收存储都可能移除本机作品，请保留导出的备份。

新版不再按 100 条或 200 万字符裁剪正文。容量不足时明确提示，仍可查看或下载当次生成的内容。旧版演出记录会复制入新作品库，原扩展设置不删；旧版已经裁掉的正文无法恢复。旧版设置中的库标识尚未同步到酒馆服务器时，请避免立即强制刷新。

写入聊天后，插件调用宿主保存，并读取指定聊天核验作品标记。若未核实保存，界面提示重试；同一条已显示消息不会再次新增。作品导入为副本时不继承已发送标记。

## 视觉与内容规则

保留奶油纸雕剧场、纸页花纹和插画封面。桌面内容放在纸页空白区；窄屏使用剧场题头与单列纸页，保持文字大小。

界面、嵌套阅读框与下载 HTML 均隐藏滚动条外观，保留滚轮、触摸与键盘滚动。文字与标题无下划线和底部装饰线。生成文档在无脚本的隔离框架内展示，仅支持 HTML/CSS 与原生展开交互，外部资源和表单会被移除。

## 剧目导入

「选剧目 → 管理剧目」支持导入单个 JSON、数组、`{"scripts": [...]}` 和带 `entries` 的世界书合集，先预览再收录。最小格式：

```json
{"title":"雨夜来信","description":"把旧日误会说清，写完一个温暖的结局。","prompt":"让 {{char}} 与 {{user}} 收到旧信，根据人物设定写完故事。"}
```

## 常见问题

- 找不到入口：确认插件目录没有多套一层，刷新酒馆，再打开扩展菜单。
- 生成失败：先确认酒馆本身可以正常回复。空响应不会覆盖已有作品。刷新网页会中断尚未完成的请求；关闭剧场面板不会中断。
- 无法保存作品：保持页面打开，先下载 HTML 或导出作品备份，再检查浏览器存储空间。
- 换设备后找不到作品：在原浏览器导出作品备份，再到新设备导入。
- 写入提示聊天已切换：检查新目标后再次点击。插件不会自行跳转或选择聊天。
- 生成内容与要求不同：本地 preview.html 使用固定示例，只有安装到真实酒馆才调用真实模型。
